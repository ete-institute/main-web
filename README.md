# ÉTÈ Institute — ete.institute

Static bilingual (EN / 中文) website for the ÉTÈ Institute.

## Structure
- `index.html` — the entire site (all pages, styles and scripts inline)
- `assets/` — every image the site uses (team, collaborators, events, logos)

## Deploy on GitHub Pages
1. Create a repository and upload **the full contents of this folder**
   (keep `index.html` at the repo root and the `assets/` folder beside it).
2. Settings → Pages → Source: `main` branch, `/ (root)`.
3. The site publishes at `https://<user>.github.io/<repo>/`.

All image paths are relative (`assets/...`), so nothing else needs configuring.
To swap a photo later, replace the file in `assets/` with the same filename.
